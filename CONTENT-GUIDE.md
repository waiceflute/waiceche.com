# WaiceChe.com Content Guide

This first version keeps the site content in `content.js` so it can later be connected to a private Admin/CMS without rebuilding the website.

## How To Give New Content

Use this format in chat or in a document:

```text
Page: Home
Content type: Image / Video / Text / Award / Media / Event
Title:
Caption:
Can publish? Yes / No
Language: EN / 繁中 / 简中
Suggested page section:
Source link or note:
Privacy note:
```

## Future Admin Fields

Each image should support:

- File
- Alt text
- Caption
- Subtitle
- Source
- Privacy note
- Ratio: 1:1 / 4:5 / 16:9 / 3:2 / custom
- Focal point
- Custom width
- Custom height
- Status: Draft / Needs Source / Ready to Publish / Public / Archived

Each content item should support:

- English content
- Traditional Chinese content
- Simplified Chinese content
- SEO title
- SEO description
- Display order
- Status

## Content Boundaries

- Waice's personal music achievements belong in Music & Education.
- Students' achievements belong only in Student Success.
- Glamour Model Agency and modeling experience support the entrepreneurship story, but should not become the main identity.
- Unsourced claims should use conservative wording or photo captions rather than strong credential language.
